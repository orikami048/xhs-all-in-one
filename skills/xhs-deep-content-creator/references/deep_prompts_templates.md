# 小红书深度高转化内容创作提示词库 (Deep Prompts Templates)

可以直接复制给大模型（如 Gemini、Claude）使用的开箱即用高阶提示词。分为四个核心生产阶段：**痛点挖掘**、**文案淬炼**、**视觉提示词生成**、**合规自检**。

---

## 阶段一：人类痛点深挖与选题反直觉构建 Prompt

```markdown
你是一位深谙小红书算法机制与人类心理学的内容策略专家。请针对以下输入领域，帮我挖掘 3 个具有“强烈痛点共鸣”且“打破常识误区”的高潜力爆款选题。

【输入领域】：[填写你的垂直领域，如：中医经方养生 / 职场AI自动化 / 极简生活]
【目标受众】：[如：长期久坐熬夜、早起水肿虚胖的打工人 / 每周写PPT写周报痛苦的职场白领]

【输出要求】：
对每个选题输出以下 4 个要素：
1. 吸引人的标题候选（≤20字，必须包含数字、痛点反差或情绪钩子，严禁AI腔）
2. 读者普遍存在的常识误区（普通人以为的错误做法）
3. 真实底层逻辑与反直觉真相（为什么错误，底层机制是什么）
4. 一句话行动方案（读者看完全篇，今天立刻能落实的一个具体动作）
```

## 阶段二：去 AI 味真实第一人称文案生成 Prompt

```markdown
请你扮演一位真实的[角色人设，如：自学经方调理好自己亚健康的打工人 / 每天用AI早下班2小时的效率控]。
请基于以下选题和事实信源，撰写一篇小红书真实经验分享笔记。

【选题】：[填写上面选定的标题]
【事实与信源支撑】：[填写明确的方剂来源、药材克重、工具操作步骤或实操数据]

【写作铁律（去AI味手术）】：
1. 绝不使用以下 AI 营销套话：“在这个快节奏的时代”、“众所周知”、“毫无疑问”、“赋能”、“颠覆”、“天花板”、“惊艳了岁月”、“宝藏”。
2. 第一人称真实视角：“说真的，以前我经常……”、“亲测踩过坑才明白……”、“后来试了两个月……”。
3. 句式长短错落：多用短句、大白话，禁止平均分配字数和死板的四字成语连发。
4. 结构布局：
   - 起手式（前两行）：描述最扎心的真实场景与体感（让人一眼产生“这不就是我吗”）。
   - 误区粉碎：指出大家最容易做错的事情（引起认知好奇）。
   - 核心干货（3点以内）：用 1️⃣ 2️⃣ 3️⃣ 标出清晰步骤/配方，给出精确克重/使用方法。
   - 避坑提醒：哪些人不能用/什么情况下不适用（展现负责态度）。
   - 走心互动呼吁：留一个真诚开放的问题引发评论区讨论。
5. 末尾必须附上合规免责声明（若为健康类）。
```

## 阶段三：3:4 视觉图与生图提示词生成 Prompt

```markdown
请为上述小红书笔记设计一套符合 3:4 比例（1200×1600）的视觉图生成方案。

【输出格式】：
1. 封面图视觉规划：
   - 顶部文案标签：[如：🌿老中医经方笔记]
   - 主标题文字：[≤16字，建议视觉重点突出哪些关键词]
   - 副标题文字：[一句话说明收益]
   - 画面视觉构图建议：[采用静物摄影还是结构化卡片排版？色彩基调是什么？]

2. AI 生图英文提示词（Midjourney / Imagen / SD 格式）：
   - Positive Prompt: (包含具体物体、光线、材质、景深、3:4 比例、摄影机位参数)
   - Negative Prompt: (排除塑料感、假人、畸形、过度饱和、水印等)

3. 结构化卡片排版内容（若采用代码渲染卡片）：
   - 卡片1：[名称] + [亮点Tag] + [两行白话实操要点]
   - 卡片2：[名称] + [亮点Tag] + [两行白话实操要点]
   - 卡片3：[名称] + [亮点Tag] + [两行白话实操要点]
```

## 阶段四：合规与违禁词自检 Prompt

```markdown
请充当小红书平台最严苛的内容审核专家。针对以下写好的小红书笔记进行合规扫描：

【待审笔记】：
[粘贴上面写好的正文与标题]

【自检项】：
1. 极限词与虚假宣传检查（最、第一、绝对、神效、100%等）。
2. 医疗宣称与疗效保证风险（是否有治愈、断根等违规医疗承诺，是否附带免责声明）。
3. 导流与违规外链（正文是否直接出现 URL、微信或敏感引导）。
4. 标题字数与阅读流畅度（标题是否超过 20 字，手机端阅读是否费劲）。

【输出结果】：
- 风险级别：[安全 / 需修改 / 高危违规]
- 待修改词句及替换建议
- 修改后的安全合规终版
```
